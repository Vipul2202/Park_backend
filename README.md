# 🅿 ParkEase — Backend API

REST API for the ParkEase peer-to-peer parking marketplace.
**Node.js 22 + Express**, JWT auth, Razorpay payments.

The mobile app and admin dashboard live in a separate repo:
[park_app](https://github.com/Vipul2202/park_app)

---

## ⚠️ Storage is in-memory

Data lives in `db/inMemoryDb.js` — it is **wiped on every restart**, including
Render's automatic redeploys and free-tier sleep. Seeded test accounts come back
each boot; anything created at runtime (bookings, listings, users) does not.
Swap in PostgreSQL before this is anything but a demo.

## 🚀 Deploy to Render

1. Push this repo to GitHub (already done if you're reading it there).
2. Render Dashboard → **New → Blueprint** → select this repo. Render reads
   [`render.yaml`](./render.yaml) and creates a free web service named
   `park-backend`.
3. When prompted, fill in the two secrets Render does not generate:
   - `RAZORPAY_KEY_ID` — e.g. `rzp_test_...`
   - `RAZORPAY_KEY_SECRET`
   - `CORS_ORIGINS` — browser origins for the admin dashboard. Safe starting
     value: `http://localhost:3000,http://localhost:5173`
4. Deploy. Your API is live at `https://park-backend.onrender.com`.

`JWT_SECRET` and `JWT_REFRESH_SECRET` are generated by Render automatically and
stay stable across deploys.

> **Free tier sleeps** after ~15 min idle. The next request takes ~50 s to wake
> the instance. If the app looks frozen on first launch, that's why — open
> `https://park-backend.onrender.com/health` first to warm it up.

### Verify the deploy

```bash
curl https://park-backend.onrender.com/health
curl https://park-backend.onrender.com/api/v1
```

### No Blueprint? Manual setup

| Setting | Value |
|---------|-------|
| Environment | Node |
| Build Command | `npm ci` |
| Start Command | `npm start` |
| Health Check Path | `/health` |

Then add every variable from [`.env.example`](./.env.example) under
**Environment**. Do **not** set `PORT` — Render injects it.

## 🔐 Security

- JWT access (7 d) + refresh (30 d) tokens, revoked on logout
- Bcrypt password hashing (10 rounds)
- RBAC: `SEEKER` / `OWNER` / `ADMIN`
- Rate limits: 20 auth attempts / 10 min, 300 requests / 15 min
- Helmet headers, CORS allowlist, Razorpay HMAC-SHA256 signature verification

Requests with **no** `Origin` header (native apps, curl) are allowed through
CORS by design — `CORS_ORIGINS` only governs browser traffic.
